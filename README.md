# library-information-system

\# Кітапхана ақпараттық жүйесі



\## Жоба туралы

Бұл жоба кітапхана жұмысын жеңілдетуге арналған.



\## Негізгі мүмкіндіктер

\- Кітаптар тізімін сақтау

\- Оқырмандарды тіркеу

\- Кітап беру және қайтаруды бақылау

\- Кітаптарды іздеу



\## Жобаның мақсаты

Кітапхана жұмысын жеңілдету және ақпаратты бір жерде сақтау.
